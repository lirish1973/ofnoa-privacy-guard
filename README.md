# Ofnoa Privacy Guard

תוסף וורדפרס לציות לחוק הגנת הפרטיות (תיקון 13), מיועד לכל האתרים של Ofnoacomps.

## מה התוסף עושה

| תחום | מה קורה |
|---|---|
| **סורק ציות** | יותר מ-40 בדיקות ב-8 קטגוריות: מיפוי ורישום, מדיניות פרטיות (סעיף-סעיף), טפסים, זכויות, Cookie, ספקים, אבטחה ותפעול. מחשב ציון 0-100, נותן לכל ממצא הנחיית תיקון וכפתור פעולה, ושולח דוח שבועי במייל כשיש ממצא קריטי |
| **ניתוח מדיניות** | בודק שקיים עמוד מפורסם, שיש אליו קישור מהפוטר, שהוא לא תבנית ברירת המחדל של וורדפרס, ושהוא מכסה: סוגי מידע, מטרות, נמענים, משך שמירה, העברה לחו"ל, Cookie, אבטחה, הודעה שאין חובה למסור מידע, עיון/תיקון/מחיקה, פרטי קשר, זהות בעל המאגר, דיוור והסרה, כל כלי צד שלישי שזוהה, ועדכון אחרי 14.8.2025 |
| **צ'קבוקס הסכמה** | מוזרק, נאכף בשרת ונרשם ביומן ב-WooCommerce (קופה רגילה + קופת בלוקים, הרשמה), הרשמה לוורדפרס, תגובות/ביקורות, Contact Form 7, Elementor Pro, WPForms, Gravity Forms ו-Fluent Forms. בכל טופס אחר עם שדה דוא"ל/טלפון: שכבת JS. כולל הודעת איסוף (סעיף 11), וצ'קבוקס שיווק נפרד שאינו מסומן מראש |
| **יומן הסכמות** | ההוכחה של בעל האתר: מועד, מקור, טופס, דוא"ל + גיבוב, IP מקוצר, גרסת המדיניות וגיבוב של נוסח ההסכמה. ייצוא ל-CSV, ביטול הסכמה לשיווק |
| **בקשות זכויות** | `[opg_rights_request]` – עיון, תיקון, מחיקה, הסרה מדיוור. אימות בדוא"ל, מועד 30 יום, היסטוריית טיפול, חיבור לכלי הייצוא והמחיקה של וורדפרס. הסרה מדיוור מתבצעת אוטומטית |
| **מסמכים** | מדיניות פרטיות (עברית + אנגלית), מדיניות Cookie, עמוד בקשות, מיפוי מאגרים, מסמך הגדרות מאגר (תקנה 2), נוהל אבטחת מידע, תוכנית תגובה לאירוע + טופס תיעוד, נספח ספקים (תקנה 15), התחייבות סודיות לעובדים, נוסחי מענה לבקשות |
| **באנר Cookie** | אישור / דחייה / קטגוריות, כפתור צף לשינוי הבחירה, Google Consent Mode v2, `fbq('consent')`, אירוע `opg_consent` ב-dataLayer, והשהיית `<script type="text/plain" data-opg-category="…">`. נכבה אוטומטית כשמותקן תוסף Cookie אחר |
| **יומן אבטחה** | התחברויות, ניסיונות כושלים, הרשאות, משתמשים, תוספים, עדכונים, ייצוא ומחיקת מידע |
| **ריבוי אתרים** | ייצוא/ייבוא הגדרות ב-JSON בין האתרים, ועדכון אוטומטי מ-GitHub Releases |

## שורטקודים

- `[opg_rights_request]` – טופס בקשות פרטיות
- `[opg_consent_box source="newsletter"]` – צ'קבוקס + הודעת איסוף לטופס מותאם
- `[opg_privacy_links]` – מדיניות | Cookie | בקשות (לפוטר)
- `[opg_policy_link]`, `[opg_cookie_settings]`

כדי שתוסף לא יזריק צ'קבוקס לטופס מסוים, מוסיפים לטופס את המחלקה `opg-skip`.

## Hooks

- `do_action( 'opg_marketing_withdrawn', $email )` – כאן מחברים את כלי הדיוור (Mailchimp/FluentCRM) להסרה בפועל
- אירוע JS: `window.addEventListener('opg:consent', e => e.detail.categories)`

## שחרור גרסה

1. מעלים את `Version:` בקובץ `ofnoa-privacy-guard.php` ואת `OPG_VERSION`
2. `gpush ofnoa-privacy-guard`
3. ה-workflow בונה את `ofnoa-privacy-guard.zip`, יוצר את התג `vX.Y.Z` ומפרסם Release. האתרים יראו את העדכון במסך התוספים תוך שעה, או מיד דרך הקישור "בדיקת עדכונים"

## הסרה

יומן ההסכמות ויומן הבקשות הם ראיות משפטיות, ולכן הם **לא נמחקים** כשמסירים את התוסף. כדי למחוק גם אותם צריך להוסיף ל-wp-config.php את השורה `define( 'OPG_DELETE_DATA', true );`.

## הבהרה

התוסף הוא כלי עזר טכני ואינו ייעוץ משפטי. כל מסמך נוצר כטיוטה שצריך לעבור עליה, ולפני פרסום מומלץ שעורך/ת דין יבדקו אותה.
